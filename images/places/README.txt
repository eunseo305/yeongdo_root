도착지 사진 넣는 곳 (지도에서 📷 사진 켜기를 누르면 보이는 사진)

1. 사진 파일 이름 = 장소 id + .jpg  (소문자, 확장자는 꼭 .jpg)
2. 장소 id는 js/02-places.js 의 id:"..." 값입니다.
   예) 흰여울문화마을  → huinnyeoul.jpg
       태종대          → taejongdae.jpg
       아르떼뮤지엄    → arte.jpg
3. 사진이 없는 장소는 지도에 "사진 준비 중" 카드가 나옵니다.
4. 가로로 긴 사진(4:3 정도)이 잘 맞고, 가운데 부분이 보이게 잘립니다.
5. 용량은 300KB 이하를 권장합니다 (휴대폰에서 빨리 뜨도록).
