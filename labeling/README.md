# 장소 라벨링

동선 추천이 손님 말에 더 잘 맞도록, 앱에 있는 장소 58곳(코스 장소 22 + 맛집 36)에 라벨을 다는 파일이에요.

| 파일 | 내용 |
|---|---|
| `장소_라벨링_58곳.csv` | 라벨을 채우는 표. 한 줄 = 장소 하나 |
| `라벨_설명.csv` | 항목마다 고르는 값과 기준, 앱에서 쓰는 곳 |

## 작업 방법

1. 엑셀이나 구글 시트로 `장소_라벨링_58곳.csv`를 열어요 (UTF-8).
2. 이미 채워진 값은 지금 앱 코드(`js/02-places.js`, `js/11-food.js`)에 있는 값이에요. 맞는지 확인하고 틀리면 고쳐요.
3. 빈칸은 `라벨_설명.csv`에 적힌 값 중에서 골라 적어요. 관심사 칸과 검수 완료 칸은 해당하면 `O`.
4. 다 본 줄은 `검수 완료`에 `O`, `담당`에 이름을 적어요.
5. 같은 곳이 두 번 나오면(피아크, 모모스, 해녀촌) 메모에 적혀 있으니 둘을 같게 맞춰요.

라벨링이 끝나면 이 값을 앱 코드로 옮기고, 새 항목(분위기 키워드, 동반, 휠체어, 가격, 예약, 외국어, 결제)을 엔진이 읽도록 고칠 예정이에요.
